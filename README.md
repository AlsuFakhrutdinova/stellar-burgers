# Проектная работа 11-го спринта

[Макет](<https://www.figma.com/file/vIywAvqfkOIRWGOkfOnReY/React-Fullstack_-Проектные-задачи-(3-месяца)_external_link?type=design&node-id=0-1&mode=design>)

[Чеклист](https://www.notion.so/praktikum/0527c10b723d4873aa75686bad54b32e?pvs=4)

Одностраничное приложение «космической бургерной»: конструктор бургера, лента заказов в реальном времени, авторизация и личный кабинет с историей заказов.

## Стек технологий:

- React + TypeScript;
- Redux Toolkit — глобальное состояние приложения;
- React Router v6 — маршрутизация, защищённые роуты, модальные окна через роутинг;
- WebSocket — обновление ленты заказов и истории заказов в реальном времени;
- Webpack — сборка проекта.

## Функциональность:

- Конструктор бургера: добавление и удаление ингредиентов, изменение порядка начинок, подсчёт стоимости;
- Оформление заказа (доступно только авторизованным пользователям);
- Лента заказов (/feed) с live-обновлением через WebSocket;
- Регистрация, авторизация, восстановление пароля;
- Личный кабинет: просмотр и редактирование профиля, история заказов (/profile/orders);
- Модальные окна для карточки ингредиента и деталей заказа, открывающиеся поверх текущей страницы при клике и как отдельная страница при прямом переходе по ссылке.

## Установка и запуск:

1. Клонировать репозиторий:

`git clone <https://github.com/AlsuFakhrutdinova/stellar-burgers> cd stellar-burgers`

2. Установить зависимости:

`npm install`

3. Создать файл .env в корне проекта и указать адрес API (пример — в .env.example). Без этой переменной приложение соберётся, но реальные запросы не смогут обратиться к API:

`BURGER_API_URL=https://norma.education-services.ru/api`

4. Запустить проект в режиме разработки:
   `npm run start`

Приложение будет доступно по адресу http://localhost:4000.

## Доступные команды:

- `npm run start` - Запуск проекта в режиме разработки с hot-reload;
- `npm run lint` - Проверка кода с помощью ESLint;
- `npm run lint:fix` - Автоматическое исправление ESLint-замечаний
- `npm run format` - Форматирование кода с помощью Prettier;
- `npm run storybook` - Запуск Storybook для просмотра UI-компонентов;

## Структура проекта

src/
components/ — React-компоненты (бизнес-логика + подключение к стору)
ui/ — презентационные компоненты (вёрстка без логики)
pages/ — компоненты страниц
services/
slices/ — Redux-слайсы (ingredients, user, burgerConstructor, order, feed, userOrders)
selectors/ — селекторы для каждого слайса
store.ts — конфигурация Redux-стора
utils/
burger-api.ts — функции для запросов к API
ws.ts — адрес WebSocket-сервера
cookie.ts — работа с cookie (токены авторизации)
types.ts — общие TypeScript-типы

## Этапы работы:

1. Разверните проект и ознакомьтесь с кодом. Все необходимые вам компоненты уже созданы и лежат в папке `src/components`

2. Настройте роутинг.

3. Напишите функционал запросов данных с сервера, используя `Redux` и глобальный `store`. Сами "ручки" уже прописаны и лежат в `utils/burger-api.ts`

4. Настройте авторизацию и создайте защищённые роуты.

## Важно:

Для корректной работы запросов к серверу необходимо добавить переменную BURGER_API_URL в окружение. Сама ссылка находится в файле `.env.example`.
